# IKONA GŁÓWNA APLIKACJI

Folder przeznaczony wyłącznie na zatwierdzony MASTER ikony aplikacji CRM „LM-Technic-Światłowód-system” oraz techniczne warianty PWA przygotowane z tego MASTER-a.

## Zasady
- Nie umieszczać tutaj grafik kart ani ekranów CRM.
- Plik źródłowy MASTER zachowujemy bez nadpisywania.
- Warianty instalacyjne PWA (np. 192×192, 512×512, maskable) powstają wyłącznie z zatwierdzonego MASTER-a.
- Manifest aplikacji może wskazywać wyłącznie zatwierdzone warianty z tego folderu.
