# KAMIEŃ MILOWY 06 — MASTER PIXEL 1:1 / WALIDACJA PRZED WDROŻENIEM

Status: ZAMROŻONY.

1. Każda karta zatwierdzona jako MASTER jest jedynym nadrzędnym wzorcem wizualnym.
2. Przed wdrożeniem aplikacji obowiązuje porównanie 1:1 z MASTER-em; nie wolno akceptować układu na podstawie „podobnego wyglądu”.
3. Dla MENU GŁÓWNEGO produkcyjny wygląd ma pochodzić bezpośrednio z pełnego MASTER-a, a nie ze zregenerowanych warstw graficznych.
4. Warstwy BASE / MEDIA / UI pozostają zasobami projektu i materiałem technicznym, ale nie mogą zastąpić pełnego MASTER-a, jeśli ich złożenie zmienia wygląd.
5. LIVE w kodzie dotyczy wyłącznie elementów rzeczywiście zmiennych: ONLINE/OFFLINE, GPS, PDF, język, tłumaczenia oraz strefy dotyku.
6. W języku polskim, jeśli element jest statyczny, jego wygląd pozostaje bezpośrednio z MASTER-a. Nie nakładać drugiego tekstu ani drugiej ramki.
7. Każda przyszła poprawka wizualna wymaga ponownej kontroli względem MASTER-a przed publikacją.

Ten standard obowiązuje cały CRM ŚWIATŁOWÓD EU.
